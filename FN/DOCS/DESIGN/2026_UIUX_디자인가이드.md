# 온도(Ondo) 2026 UI/UX 디자인 가이드

> **대상:** FN(프론트엔드) 개발팀 · 디자이너  
> **버전:** 2026.1  
> **목적:** 학생·교사가 **편하게 읽고, 부담 없이 사용**할 수 있는 학교 상담 플랫폼 UI/UX 기준

---

## 1. 디자인 철학

### 1.1 한 줄 원칙

> **"읽기 쉽고, 마음이 가벼운 화면"**

온도는 상담·기분 기록·학교 생활 정보를 다루는 서비스입니다. 화면은 정보를 쌓기보다 **안심감과 명확함**을 먼저 전달해야 합니다.

### 1.2 2026 트렌드 반영 방향

| 트렌드 | 온도 적용 방식 |
|--------|----------------|
| **Calm Tech** (차분한 기술) | 자극적인 색·애니메이션 최소화, 여백과 부드러운 톤 우선 |
| **Bento UI** | 시간표·기분·상담 현황을 카드 단위로 한눈에 배치 |
| **Soft Minimalism** | 둥근 모서리, 은은한 그림자, 단순한 정보 계층 |
| **Inclusive Design** | 큰 글씨·터치 영역, 색만으로 상태 구분하지 않기 |
| **Adaptive Theme** | 라이트/다크 모드, `prefers-reduced-motion` 존중 |
| **Micro-interaction** | 버튼·완료·저장 시 짧고 명확한 피드백 |
| **Mobile-first** | 학생의 주 사용 환경은 스마트폰 — 모바일 기준 설계 |

### 1.3 사용자별 UX 우선순위

| 사용자 | 핵심 니즈 | UI 대응 |
|--------|-----------|---------|
| **학생** | 빠른 이해, 낮은 심리적 부담 | 큰 본문, 친근한 문구, 단계별 입력 |
| **교사** | 효율적 확인·응답 | 스캔 가능한 리스트, 상태 뱃지, 필터 |
| **관리자** | 데이터 밀도 | 학생 화면보다 조밀하되 가독성 유지 |

## 2. 브랜드 & 컬러 시스템

### 2.1 브랜드 키워드

`따뜻함` · `신뢰` · `안전` · `명료함`

서비스명 **온도**는 '마음의 온기'와 '측정 가능한 상태'를 동시에 연상시킵니다. 시각 언어는 **차가운 IT 느낌보다 따뜻한 학교 공간**에 가깝게 유지합니다.

### 2.2 Primary Palette

```css
:root {
  /* Brand — Warm Sky Blue */
  --color-primary-50:  #eff6ff;
  --color-primary-100: #dbeafe;
  --color-primary-500: #3b82f6;  /* 기본 CTA */
  --color-primary-600: #2563eb;  /* hover, 강조 링크 */
  --color-primary-700: #1d4ed8;  /* pressed */

  /* Neutral — Slate (눈 fatigue 감소) */
  --color-neutral-50:  #f8fafc;
  --color-neutral-100: #f1f5f9;
  --color-neutral-200: #e2e8f0;
  --color-neutral-400: #94a3b8;
  --color-neutral-600: #475569;
  --color-neutral-800: #1e293b;
  --color-neutral-900: #0f172a;

  /* Surface */
  --color-bg-page:     linear-gradient(180deg, #eff6ff 0%, #f8fafc 100%);
  --color-bg-card:     #ffffff;
  --color-bg-elevated: #ffffff;

  /* Semantic */
  --color-success: #059669;
  --color-success-bg: #ecfdf5;
  --color-warning: #d97706;
  --color-warning-bg: #fffbeb;
  --color-error:   #dc2626;
  --color-error-bg:   #fef2f2;
  --color-info:    #0284c7;
  --color-info-bg:    #e0f2fe;
}
```

### 2.3 역할별 Accent (뱃지·아이콘)

| 역할 | 배경 | 텍스트 | 용도 |
|------|------|--------|------|
| 학생 | `#dbeafe` | `#1d4ed8` | 학생 탭·프로필 |
| 교사 | `#dcfce7` | `#166534` | 교사 탭·응답 |
| 관리자 | `#fef3c7` | `#92400e` | 관리 기능 |
| 상담 대기 | `#fef3c7` | `#b45309` | PENDING |
| 상담 진행 | `#dbeafe` | `#1d4ed8` | IN_PROGRESS |
| 상담 완료 | `#dcfce7` | `#166534` | COMPLETED |

> **접근성:** 색상 외에 **아이콘·텍스트 라벨**을 반드시 함께 사용합니다.

### 2.4 다크 모드 (2026 기본 지원 권장)

```css
@media (prefers-color-scheme: dark) {
  :root {
    --color-bg-page:     #0f172a;
    --color-bg-card:     #1e293b;
    --color-bg-elevated: #334155;
    --color-neutral-800: #f1f5f9;
    --color-neutral-600: #cbd5e1;
  }
}
```

다크 모드에서도 Primary Blue는 **밝기 `#60a5fa` 이상**으로 올려 대비(4.5:1)를 확보합니다.

## 3. 타이포그래피

### 3.1 폰트 스택

학생 가독성을 위해 **한글 웹폰트**를 기본으로 사용합니다.

```css
:root {
  --font-sans: "Pretendard Variable", Pretendard, -apple-system,
               BlinkMacSystemFont, "Segoe UI", sans-serif;
  --font-mono: "Pretendard Variable", ui-monospace, monospace;
}
```

| 우선순위 | 폰트 | 이유 |
|----------|------|------|
| 1 | Pretendard | 2026 국내 서비스 표준, Variable Font, 가독성 우수 |
| 2 | 시스템 폰트 | 웹폰트 로딩 전 FOIT 방지 |

### 3.2 타입 스케일 (학생 화면 기준)

| 토큰 | 크기 | 행간 | 굵기 | 용도 |
|------|------|------|------|------|
| `display` | 32px → 28px (mo) | 1.25 | 700 | 랜딩·환영 |
| `h1` | 24px | 1.35 | 700 | 페이지 제목 |
| `h2` | 20px | 1.4 | 600 | 섹션·카드 제목 |
| `h3` | 18px | 1.45 | 600 | 서브 섹션 |
| `body-lg` | **17px** | **1.7** | 400 | **학생 본문 (권장)** |
| `body` | 15px | 1.65 | 400 | 일반 본문 |
| `caption` | 13px | 1.5 | 400 | 보조 설명 |
| `label` | 14px | 1.4 | 600 | 폼 라벨 |

> **학생 화면 규칙:** 상담 작성·약관·안내 문구는 최소 `body-lg`(17px)를 사용합니다.  
> **한 줄 길이:** 본문은 **35~45자(한글 기준)** 이내로 줄바꿈을 유도합니다.

### 3.3 문장 톤 (UX Writing)

| ❌ 피하기 | ✅ 권장 |
|-----------|---------|
| "필수 입력 항목 누락" | "아직 적지 않은 항목이 있어요" |
| "오류 발생" | "다시 한번 확인해 주세요" |
| "제출" | "작성 완료" / "보내기" |
| 법률 문구 그대로 노출 | 짧은 요약 + '자세히 보기' |

## 4. 레이아웃 & 그리드

### 4.1 브레이크포인트

```css
--bp-sm:  640px;   /* 모바일 → 태블릿 */
--bp-md:  768px;
--bp-lg:  1024px;  /* 태블릿 → 데스크톱 */
--bp-xl:  1280px;
```

### 4.2 컨테이너

| 화면 유형 | max-width | 좌우 padding |
|-----------|-----------|--------------|
| 학생·교사 일반 | 720px | 16px (mo) / 24px (dt) |
| 대시보드·관리 | 1200px | 24px |

### 4.3 Bento Grid (2026 권장)

홈·대시보드는 **크기가 다른 카드**를 조합해 정보 밀도와 시각적 흥미의 균형을 맞춥니다.

```
┌─────────────────────┬──────────┐
│  오늘 기분 (2×1)     │ 시간표   │
│                     │ (1×2)    │
├──────────┬──────────┤          │
│ 상담현황 │ 급식     │          │
└──────────┴──────────┴──────────┘
```

- 카드 간격(gap): **16px** (모바일), **20px** (데스크톱)
- 카드 내부 padding: **20~24px**

### 4.4 여백 토큰 (8pt 시스템)

```
4 · 8 · 12 · 16 · 20 · 24 · 32 · 48 · 64 (px)
```

섹션 간 수직 간격: **32px** (학생), **24px** (관리)

## 5. 컴포넌트 가이드

### 5.1 버튼

| 유형 | 스타일 | 최소 높이 |
|------|--------|-----------|
| Primary | `--color-primary-600` 배경, 흰 텍스트 | **48px** (학생) / 44px (일반) |
| Secondary | `--color-neutral-900` 또는 outline | 44px |
| Ghost | 배경 없음, primary 텍스트 | 44px |
| Danger | `--color-error-bg` + error 텍스트 | 44px |

```css
.btn {
  border-radius: 12px;
  padding: 12px 20px;
  font-weight: 600;
  font-size: 15px;
  transition: background 0.15s ease, transform 0.1s ease;
}
.btn:active { transform: scale(0.98); }
.btn:focus-visible {
  outline: 3px solid var(--color-primary-100);
  outline-offset: 2px;
}
```

> **터치 타겟:** 학생-facing 버튼은 **최소 48×48px** (WCAG 2.2 권장)

### 5.2 카드

```css
.card {
  background: var(--color-bg-card);
  border-radius: 16px;
  padding: 24px;
  box-shadow: 0 4px 24px rgba(15, 23, 42, 0.06);
  border: 1px solid rgba(226, 232, 240, 0.8);
}
```

- **Soft shadow:** 과한 글로우·네온 금지
- **호버(데스크톱):** `translateY(-2px)` + shadow 약간 증가

### 5.3 입력 필드 (Form)

```css
.input {
  min-height: 48px;
  padding: 12px 16px;
  border: 1.5px solid var(--color-neutral-200);
  border-radius: 12px;
  font-size: 16px; /* iOS 줌 방지 */
}
.input:focus {
  border-color: var(--color-primary-500);
  box-shadow: 0 0 0 4px var(--color-primary-50);
}
```

| 규칙 | 설명 |
|------|------|
| 라벨 | 입력 위에 배치, `*` 대신 "(필수)" 텍스트 |
| 도움말 | placeholder만으로 안내하지 않기 |
| 에러 | 필드 아래 빨간 문구 + 아이콘, border color 변경 |
| 긴 입력 | 상담 내용은 **textarea** 최소 4줄, 글자 수 표시 |

### 5.4 네비게이션

**학생·교사 (모바일):** 하단 탭 바 (2026 모바일 표준)

```
[ 홈 ] [ 상담 ] [ 기분 ] [ 더보기 ]
```

- 아이콘 + 짧은 라벨
- 활성 탭: primary 색 + 굵은 라벨
- Safe area (`env(safe-area-inset-bottom)`) 반영

**데스크톱:** 좌측 사이드바 또는 상단 헤더 (max 5개 1depth)

### 5.5 상태 뱃지

```css
.badge {
  display: inline-flex;
  align-items: center;
  gap: 4px;
  padding: 4px 10px;
  border-radius: 999px;
  font-size: 12px;
  font-weight: 600;
}
```

### 5.6 빈 상태 (Empty State)

- 일러스트 또는 이모지 1개 (과하지 않게)
- **한 줄 설명** + **다음 행동 버튼 1개**
- 예: "아직 작성한 상담이 없어요" → [첫 상담 작성하기]

### 5.7 로딩 & 스켈레톤

- 전체 화면 스피너 지양 → **스켈레톤 UI** (카드 형태 유지)
- 300ms 이상 지연 시에만 로딩 표시 (perceived performance)
- `prefers-reduced-motion: reduce` 시 애니메이션 없이 페이드만

## 6. 학생 친화 UX 패턴

### 6.1 인지 부하 줄이기

1. **한 화면 = 한 목적** (상담 작성 / 목록 / 상세 분리)
2. **Progressive Disclosure:** 고급 옵션은 '더 보기' 뒤에
3. **3단계 이하** 마법사(Wizard) — 회원가입·사전상담 작성
4. **기본값 제공:** 가능한 항목은 미리 선택 또는 추천

### 6.2 상담·민감 정보 UX

| 원칙 | 구현 |
|------|------|
| 심리적 안전 | 부드러운 색, 경고성 빨강 남용 금지 |
| 명확한 동의 | 토글 + 짧은 요약, 전문은 접이식 |
| 프라이버시 | 민감 필드 마스킹, 세션 타임아웃 안내 |
| 되돌리기 | 삭제 전 확인 + "잠시 후 자동 저장" |

### 6.3 기분(Mood) 기록 UI

- **이모지 + 짧은 라벨** (색맹 대응)
- 5단계 이하 스케일 (선택 피로 감소)
- 탭 한 번으로 기록 완료 → 즉시 피드백 ("오늘 기분을 기록했어요 ✓")

### 6.4 피드백 & 마이크로 인터랙션

| 행동 | 피드백 |
|------|--------|
| 저장 성공 | 토스트 2~3초, success 색 |
| 네트워크 오류 | 재시도 버튼 포함 배너 |
| 버튼 클릭 | 0.1s scale + haptic(네이티브 시) |
| 페이지 전환 | 200ms fade/slide (reduce-motion 시 instant) |

## 7. 접근성 (A11y) — 필수 기준

| 항목 | 기준 |
|------|------|
| 텍스트 대비 | WCAG AA — 4.5:1 (본문), 3:1 (대형 텍스트) |
| 포커스 | `:focus-visible` 링 모든 인터랙티브 요소 |
| 키보드 | Tab 순서 논리적, 모달 포커스 트랩 |
| 스크린 리더 | `aria-label`, 폼 `label for` 연결 |
| motion | `@media (prefers-reduced-motion: reduce)` |
| 터치 | 44×44px 최소 (학생 UI 48px) |

## 8. 아이콘 & 일러스트

### 8.1 아이콘

- **Lucide** 또는 **Phosphor** (2026 오픈소스 표준, 일관된 stroke)
- 크기: 20px (인라인), 24px (탭·버튼)
- stroke-width: 1.75~2px

### 8.2 일러스트 톤

- Flat + soft gradient, **사람 중심** (고립감·불안 유발 이미지 지양)
- Lottie 등 **짧은 루프**는 Empty State·온보딩에만 제한적 사용

## 11. 화면별 체크리스트

개발·QA 시 아래 항목을 확인합니다.

### 학생 화면

- [ ] 본문 17px 이상, 행간 1.65 이상
- [ ] CTA 버튼 48px 높이
- [ ] 에러·성공 메시지가 친근한 문구인가
- [ ] 상담·민감 입력에 저장/동의 UX가 있는가
- [ ] 모바일 하단 탭·safe area 적용

### 교사 화면

- [ ] 상담 목록 스캔 가능 (상태 뱃지 + 날짜)
- [ ] 미읽음 구분이 색+아이콘으로 가능한가
- [ ] 일괄 작업 시 확인 단계 있는가

### 공통

- [ ] Lighthouse Accessibility ≥ 90
- [ ] 다크 모드 대비 충족
- [ ] `prefers-reduced-motion` 테스트 완료

## 12. 레퍼런스 & 금지 사항

### 참고 레퍼런스 (무드보드)

- **Calm** — 차분한 멘탈 헬스 UI
- **Linear** — 정보 밀도와 가독성 균형 (교사·관리)
- **Kakao / Toss** — 국내 학생 친숙한 톤·터치 패턴
- **Apple HIG 2025+** — 접근성·Dynamic Type

### 금지 (Don't)

- ❌ 순수 검정 `#000` 본문 (눈 fatigue)
- ❌ 3px 미만 font size
- ❌ 자동 재생 사운드·과한 parallax
- ❌ 상태 구분을 **색상만**으로 표현
- ❌ 상담 화면에 **긴급/경고** 톤 남용 (불안 유발)
- ❌ 클릭 가능해 보이지 않는 텍스트 링크

## 부록: 기존 BN 템플릿과의 정렬

현재 백엔드 템플릿(`BN/src/main/resources/templates/`)에서 사용 중인 값과 본 가이드는 **호환**됩니다.

| 항목 | 기존 값 | 2026 가이드 |
|------|---------|-------------|
| Primary | `#2563eb` | `--color-primary-600` 동일 |
| Page BG | `#f4f7fb` / gradient | `--color-bg-page` 확장 |
| Card radius | 16px | `--radius-lg` 동일 |
| Button min-height | 44px | 학생 UI **48px**로 상향 권장 |
| Font | Segoe UI | **Pretendard** 우선 |

FN 프론트엔드 구현 시 위 CSS 변수를 `tokens.css` 또는 Tailwind theme extension으로 분리해 사용하는 것을 권장합니다.
