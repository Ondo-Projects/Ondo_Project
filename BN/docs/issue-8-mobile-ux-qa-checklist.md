# Issue #8 모바일 UX — 수동 QA 체크리스트

Chrome DevTools **디바이스 툴바**(Ctrl+Shift+M)로 아래 3개 뷰포트에서 동일 항목을 확인합니다.

| 프리셋 | 논리 해상도 | 확인 목적 |
|--------|-------------|-----------|
| **iPhone SE** | 375 × 667 | 좁은 iOS — 줄바꿈·2열 그리드·헤더 |
| **iPhone 12** | 390 × 844 | 일반 iOS — Safe area·키보드·스크롤 |
| **Galaxy S20** | 360 × 800 | 좁은 Android — 360px 레이아웃·chip wrap |

- **기준 URL**: `http://localhost:8081` (앱 기동 후)
- **브레이크포인트**: CSS `@media (max-width: 640px)` 적용 구간
- **합격 기준**: 가로 스크롤 없음(의도된 테이블 스크롤 제외), 터치 영역 ≥ 44px, 주요 콘텐츠 잘림 없음

## DevTools 실행 방법

1. Chrome에서 `http://localhost:8081` 접속
2. F12 → **Toggle device toolbar** (Ctrl+Shift+M)
3. 상단에서 **iPhone SE** 선택 → 위 표 순서대로 체크
4. **iPhone 12**, **Galaxy S20** 반복
5. (선택) Responsive 모드 **320px** 너비로 C1·S3 추가 spot check

### 키보드 가림 확인 (join, login)

1. iPhone 12 프리셋 유지
2. 입력란 탭 → 가상 키보드 표시 (DevTools에서 키보드 아이콘 또는 실기기)
3. focus 필드가 viewport 중앙 근처로 스크롤되는지 확인

### 터치 영역 측정

1. Elements 패널에서 버튼/chip 선택
2. Computed → box model에서 **height ≥ 44px** 확인
