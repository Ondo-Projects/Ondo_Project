# Issue #14 공통 홈 `/home` — 수동 QA 체크리스트

Chrome DevTools **디바이스 툴바**(Ctrl+Shift+M)로 아래 3개 뷰포트에서 확인합니다.

| 프리셋 | 논리 해상도 | 확인 목적 |
|--------|-------------|-----------|
| **iPhone SE** | 375 × 667 | 좁은 iOS — 헤더·퀵링크 wrap |
| **iPhone 12** | 390 × 844 | 일반 iOS — Safe area·스크롤 |
| **Galaxy S20** | 360 × 800 | 좁은 Android — 360px·2열 퀵링크 |

- **기준 URL**: `http://localhost:8081/home` (학생·교사 로그인 후)
- **브레이크포인트**: CSS `@media (max-width: 640px)`, `@media (max-width: 360px)`
- **합격 기준**: 가로 스크롤 없음, 터치 영역 ≥ 44px, 역할별 블록 오표시 없음

## DevTools 실행 방법

1. `cd BN` → `./gradlew bootRun` (또는 `.\gradlew.bat bootRun`)
2. Chrome `http://localhost:8081/login`
3. F12 → **Toggle device toolbar** (Ctrl+Shift+M)
4. 학생 계정 로그인 → `/home` → **HS·H·C·N** 항목 체크
5. 로그아웃 → 교사 계정 → `/home` → **HT·H·C·N** 항목 체크
6. (선택) Responsive **320px** 너비 spot check — C1, HS2

### 터치 영역 측정

1. Elements → `.btn-quick` 또는 `.btn-primary` 선택
2. Computed → **height ≥ 44px**
